Αντικατάστησε **μόνο** τα αρχεία της εφαρμογής στον υπάρχοντα δημόσιο φάκελο GitHub Pages, διατηρώντας τη δομή `icons/`. Αν το repository δημοσιεύει από τη ρίζα, βάλε τα περιεχόμενα του φακέλου `Y.E.F.K.K-main/` στη ρίζα του repository. Δεν ανεβάζουμε μισθοδοσίες ή προσωπικά PDF στο δημόσιο repository.

## Αμετάβλητα
Ο κλειδωμένος συγκριτής Κερμανίδη, οι πίνακες `oldPayData/newPayData`, και οι υπάρχοντες υπολογισμοί κύριας σύνταξης **δεν τροποποιήθηκαν** στην v8.8. Η εφαρμογή εξακολουθεί να χρησιμοποιεί ενδεικτικά ποσά επικουρικής/ΜΤΠΥ. Δεν παρουσιάζονται ως εξακριβωμένα.

## Τι είναι τεκμηριωμένο και τι όχι
Τα ετήσια PDF 2011–2026 είναι σαρωμένα. Ο προηγούμενος κατάλογος 190 μηνών δεν αποδεικνύει συμφωνία των πραγματικών κρατήσεων ανά μήνα. Η επικουρική χρησιμοποιεί proxy 90% για το προ-2015 τμήμα αν δεν εισαχθεί βάση, και proxy 6% εισφορών για το 2015+ μαζί με ενδεικτική ράντα. Το ΜΤΠΥ χρησιμοποιεί 0,215% και προβλεπόμενο βασικό μισθό. Οι πραγματικές εισφορές, οι συντελεστές και οι κανόνες για το έτος εξόδου πρέπει να επιβεβαιωθούν πριν θεωρηθούν οριστικά. Μην ερμηνεύεις τα 266,38 € και 205,11 € ως πιστοποιημένα ποσά.

## Πρωτόκολλο επόμενων ενημερώσεων
1. Αποθήκευσε αυτό το ZIP ως βασική έκδοση.
2. Όταν υπάρχει νέα μισθοδοσία ή τελικό ΦΕΚ, δώσε το **μαζί με το ZIP** σε νέα συνομιλία, ζητώντας νέα έκδοση.
3. Η νέα έκδοση οφείλει να καταγράψει ακριβώς ποιες βάσεις/κρατήσεις/συντελεστές άλλαξαν, να ελέγξει τον κώδικα και να διατηρήσει τον συγκριτή ανέπαφο.
4. Προσωπικά εκκαθαριστικά παραμένουν ιδιωτικά, εκτός δημόσιου GitHub.
